# 프로젝트 개요

## 프로젝트 목적
본 프로젝트의 목적은 사용자의 일상 업무와 할 일 관리를 능동적으로 지원하는 지능형 웹 애플리케이션을 구축하는 것이다. 단순한 목록 작성을 넘어 사용자의 맥락과 업무 문서를 종합적으로 이해하여 최적의 실행 계획을 제안하는 실질적인 생산성 도구를 지향한다.

## 현재 사용 기술
본 웹 애플리케이션은 간결하고 안정적인 웹 표준 기술 스택을 기반으로 제작되었다. 백엔드는 Node.js 환경과 Express 프레임워크를 기반으로 구축하여 가볍고 유연한 라우팅 및 API 처리를 담당한다. 프런트엔드는 복잡한 외부 프레임워크 도입 없이 순수 HTML, CSS, JavaScript로 구현되어 브라우저에서 높은 실행 성능과 가벼운 동작을 보장한다.

## Todo 앱의 주요 기능
사용자는 직관적인 웹 인터페이스를 통해 할 일을 손쉽게 관리할 수 있다. 개별 Todo 항목에는 제목과 세부 내용뿐만 아니라 priority(높음, 보통, 낮음)와 목표 실행 일자인 date를 지정할 수 있다. 특히 today 필터를 통해 오늘 집중해야 할 작업만 신속하게 조회하고 처리할 수 있는 전용 뷰를 제공한다. 현재 모든 Todo 데이터는 브라우저 내부의 localStorage에 안전하게 영속화되어 별도의 복잡한 데이터베이스 설정 없이도 브라우저를 다시 열었을 때 작업을 그대로 이어갈 수 있다.

## AI 챗봇과 Tool Calling의 역할
애플리케이션에 내장된 AI Chat 인터페이스는 단순한 텍스트 기반 대화를 넘어선 지능형 비서 역할을 수행한다. AI 챗봇은 자연어 대화 흐름 속에서 사용자의 의도를 분석하며, Todo Tool Calling 메커니즘을 활용하여 실제 할 일 데이터를 조작한다. 이를 통해 사용자가 "오늘 마감인 기획서 작성 작업 등록해줘"라고 입력하면, 챗봇이 백엔드 시스템과 통신하여 해당 파라미터를 추출하고 정확한 도구를 호출함으로써 시스템 상태를 직접 갱신한다.

## RAG 도입 배경과 원칙
향후 프로젝트에는 RAG(Retrieval-Augmented Generation) 아키텍처가 본격적으로 도입될 예정이다. Todo 목록만으로는 파악하기 어려운 업무 배경, 프로젝트 문서, 개발 규칙 등의 외부 컨텍스트를 검색하여 AI에게 제공함으로써 답변의 신뢰도를 획기적으로 높이고 환각 현상을 억제하기 위함이다. 본 프로젝트에서는 기존 시스템 안정성 보장, 간결한 아키텍처 유지, 엄격한 데이터 보안 준수를 핵심 원칙으로 삼는다.

## 향후 발전 방향
본 시스템의 궁극적인 지향점은 단순 작업 도우미를 넘어 사용자의 문서와 일정을 총체적으로 조율하는 AI Work Coach로의 진화다. 문서를 분석하여 누락된 할 일을 선제적으로 발굴하고, 우선순위를 정렬하며, 일정 충돌을 방지하는 통합 업무 코칭 환경을 완성해 나갈 것이다.

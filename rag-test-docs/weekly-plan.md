# 이번 주 개발 계획

## 주간 개요
이번 주 개발 스프린트의 핵심은 Todo 애플리케이션의 기본 안정성을 다지는 동시에 RAG 파이프라인의 핵심 모듈을 단계적으로 구축하는 것이다. RAG 문서 저장과 chunking은 이번 주 초에 구현할 예정이며, embedding과 vector search는 그 다음 단계에서 진행한다. 최종 목표는 문서 검색 결과를 참고하면서 Todo Tool Calling까지 수행하는 AI Work Coach다.

## 세부 작업 내역

### RAG 문서 업로드 기능 구현
- 상태: 완료
- 우선순위: 높음
- 설명: 관리자 및 사용자가 Markdown 형식의 문서를 서버에 등록할 수 있는 기본 API 엔드포인트와 파일 업로드 처리기를 구현 완료하였다. 업로드된 문서는 메타데이터와 함께 임시 저장소에 안전하게 격리된다.

### Markdown chunking 파이프라인 제작
- 상태: 진행 중
- 우선순위: 높음
- 설명: 문서를 효율적인 검색 단위로 분할하는 모듈을 작성하고 있다. 제목 계층 구조(titlePath)를 정확히 추출하여 청크 메타데이터에 보존하는 로직을 집중 개발 중이다.

### embedding 모델 연동 및 vector search 구현
- 상태: 예정
- 우선순위: 높음
- 설명: OpenAI Responses API 규격과 호환되는 임베딩 생성 프로세스를 연동하고, 벡터 간 유사도 측정을 통한 vector search 기능을 개발 서버에 안착시킬 예정이다.

### RAG와 Chat 대화 인터페이스 통합
- 상태: 예정
- 우선순위: 보통
- 설명: 사용자 질문 입력 시 벡터 데이터베이스에서 관련 청크를 추출하고, 이를 시스템 프롬프트의 컨텍스트로 결합하여 대화 모델에 전달하는 통합 오케스트레이션을 완성한다.

### 문서 출처 표시 기능
- 상태: 예정
- 우선순위: 보통
- 설명: AI가 RAG 컨텍스트를 기반으로 답변을 생성했을 때, 참고한 원본 문서 제목과 소제목 위치를 응답 하단에 링크 형태로 명시하여 신뢰도를 높인다.

### Todo Tool Calling과 RAG 결합 처리
- 상태: 진행 중
- 우선순위: 높음
- 설명: 문서에서 발견된 실행 과제를 사용자의 Todo 목록으로 즉시 전환할 수 있도록 기존 Tool Calling 구조와 검색 컨텍스트 간 파라미터 매핑을 최적화하고 있다.

### 모바일 UI 개선
- 상태: 완료
- 우선순위: 보통
- 설명: 작은 모바일 화면에서도 대화창과 할 일 목록, today 및 priority 필터가 어색함 없이 전환되도록 반응형 CSS 레이아웃을 정비하였다.

### 전 기능 회귀 테스트
- 상태: 예정
- 우선순위: 보통
- 설명: 신규 RAG 모듈과 기존 localStorage 기반 할 일 관리 기능이 충돌 없이 원활히 연동되는지 종합 회귀 테스트를 실시한다.
